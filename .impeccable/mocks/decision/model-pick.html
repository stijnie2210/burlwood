Git client · Model v0.3.0

A fast, free git client for the Mac.

Read history as a graph, stage single hunks, settle conflicts. One native app on your system git: no account, no subscription, no telemetry.

Unit 2 · Commits

Read the history.

Every branch, tag and stash gets its own lane, and the graph scrolls smoothly through thousands of commits. ⌘F finds one.

Checkout, branch, tag, revert or reset from any row. A hard reset can be undone.

Unit 3 · Working tree

Shape the commit.

Stage a whole file or a single hunk; the patch is built from exactly the lines on screen. Discard has Undo.

Pick ours or theirs per conflict, diff3 and zdiff3 aware.

Specifications

What's inside.

EngineYour system git, so your config, hooks and SSH agent apply
BuildOne native binary: Go and Vue 3 in the system webview, no Electron
RemotesBackground fetch, pull with autostash, push with upstream, force-with-lease
Errorsgit's output as one sentence and a next step; the raw output one click away
TabsSeveral repositories at once, restored on the next launch
LicenceGPL-3.0. No account, no subscription, no telemetry
Installation

Plug it in.

Input 1

macOS

Universal DMG. Not signed with an Apple Developer ID, so clear the quarantine flag once.

xattr -dr com.apple.quarantine \
  /Applications/Burlwood.app
Input 2

Linux

AppImage. Needs WebKit2GTK 4.1.

Input 3

Windows

Zip with burlwood.exe.
