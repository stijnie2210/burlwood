# Surface: Burlwood website (single page)

Mode: Persuade. Astro project in `website/`, built static; no hosting chosen yet.

- **Audience:** Mac developers who use a git GUI (or want one) and land from GitHub or a link.
- **Job:** download the macOS build; Linux and Windows are secondary but findable.
- **Proof:** the real app screenshots (`assets/screenshots/`), the README's feature facts, the icon. No invented numbers, quotes or logos.
- **Constraints from the user:** no startup SaaS hype; must feel designed, not README-like; do not mention pre-1.0 status or backups.
- **Memorable moment:** the knot between "burl" and "wood", and grain that bends around the pointer, mirrored across the gutter (bookmatched).

## Direction contract
